# Enchanted Duplication — NeoForge 1.21.1

This project is prepared to build the NeoForge 1.21.1 mod through GitHub Actions.

## Build

1. Upload the contents of this folder to a GitHub repository. GitHub supports dragging a folder into the Upload files page.
2. Open the repository's **Actions** tab.
3. Open **Build Enchanted Duplication**.
4. The workflow runs automatically after the upload. You can also use **Run workflow**.
5. When it finishes successfully, open the run and download the artifact named **EnchantedDuplication-NeoForge-1.21.1**.
6. The downloaded ZIP contains the built `.jar`; put that JAR in `.minecraft/mods`.

Minecraft: 1.21.1
NeoForge: 21.1.216
Java: 21
